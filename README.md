# AI RAG Research Assistant

An AI-powered Research Assistant that uses Retrieval Augmented Generation (RAG) to answer questions from uploaded documents.

## Features

* PDF Upload
* Text Extraction
* Chunking Strategies
* Embeddings
* FAISS Vector Search
* Gemini LLM Integration
* Source Citations
* Agentic RAG (Planned)

## Tech Stack

* Python
* Streamlit
* Gemini
* LangChain
* FAISS
* Sentence Transformers

## Project Status

Currently building the document ingestion pipeline.
